# Security Policy

## Supported Versions

Only the latest release on the `main` branch receives active security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | Yes                |
| < 0.1   | No                 |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

To report a vulnerability, please use [GitHub Private Vulnerability Reporting](https://github.com/LeonidMajbits/phantom-workstation/security/advisories/new).

Reports should include:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions to reproduce the issue.
- Relevant macOS versions and system configurations.

Vulnerabilities will be evaluated promptly, and verified fixes will be prioritized for release on the `main` branch.
